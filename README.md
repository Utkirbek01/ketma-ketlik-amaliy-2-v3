# Basic. Ketma-ketlik bo'limi uchun 2-amaliy vazifa (C# / .NET 8)

Ishga tushirish:

```bash
dotnet run
```

Dastur ketma-ket 3 ta vazifani bajaradi:

1. **Kalkulyator** — ikkita son va operatsiya (`+`, `-`, `*`, `/`) kiritiladi, natija chiqariladi. Nolga bo'lish va noto'g'ri operatsiya tekshiriladi.
   `5`, `+`, `5` → `10`
2. **1 dan N gacha yig'indi** — musbat butun N kiritiladi, 1..N yig'indisi chiqariladi.
   `10` → `55`
3. **Paritet tekshiruvi** — kiritilgan son juft yoki toq ekanligi chiqariladi.
   `3` → `"Toq"`
